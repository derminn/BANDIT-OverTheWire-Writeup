---

## What is Bandit?

Bandit is a beginner-friendly wargame designed to teach the fundamentals of
Linux and the command line. Each level presents a challenge that must be solved
using Linux commands, and the goal is to find the password to access the next level via SSH.

It is widely recommended as the **first wargame** for anyone getting started
with Linux, networking, and cybersecurity.

It covers real-world concepts like:
- Linux file system navigation and permissions
- SSH connection and key-based authentication
- File manipulation and searching
- Process management and job control
- Networking basics (ports, services)
- Shell scripting and piping commands
- Data encoding (Base64, hex, compression)

## Tools & Commands Used

- `ssh`, `scp` — remote login and file transfer
- `ls`, `cd`, `cat`, `find`, `grep` — file navigation and searching
- `file`, `strings`, `xxd` — file inspection and hex analysis
- `base64`, `tr`, `gzip`, `tar`, `bzip2` — encoding and compression
- `nc` (netcat) — networking and port communication
- `chmod`, `chown` — file permissions
- `cron`, `crontab` — scheduled tasks
- `git` — version control challenges
- Bash scripting and piping (`|`, `>`, `>>`)

---

## Key Takeaways

- Confident navigating and operating entirely within a Linux terminal
- Understanding of how SSH, file permissions, and processes work at the OS level
- Practical experience with data encoding, compression, and shell scripting
- Strong foundation for working in ML/AI development environments that rely on Linux servers
